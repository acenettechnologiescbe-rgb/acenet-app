Setup & Administration

LAN Network Setup

  • 1
    Save this file on server computer. Eg: C:\AcenetSuite\acenet.html
  • 2
    Open Command Prompt and run: python -m http.server 8080
  • 3
    Find server IP: run ipconfig (Windows) or ifconfig (Mac/Linux)
  • 4
    All devices on same WiFi open: http://[server-ip]:8080/acenet.html
  • 5
    Each team logs in with their credentials. Real-time sync works between browser tabs on same machine.
